# Tool Scripts

Handy scripts.

| Folders | description |
|---|---|
| Console | Command-line scripts. |
| Proxy | Configs or scripts related to system proxy. |

## File Description

### Console

+ `deepseek_translator.sh`

  commandline translator using deepseek API . `jq` command is required

+ `GT_bash_client.sh`

  commandline google translator. `xxd` and `jq` commands are required.

+ `bashrc_UDF.sh`
  
  User-defined functions which can be appended to `.bashrc` or `.zshrc` files.

+ `SSH_server_TOTP_2FA_auto_login.py`

  A script for generating 2FA authentication code in Terminal. With the help of Linux `expect` command, users can login to SSH server which requires TOTP 2FA verification without manually entering password or 2FA code. Follow the instruction in this script, and enjoy the automatic login.

### Proxy

+ `AppleAdd.list`

  An additional apple url rule list.
